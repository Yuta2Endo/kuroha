# Юридические черновики Kuroha

Статус: черновики для проверки юристом. Это не юридическая консультация и не
готовые документы для публикации.

Все шесть документов написаны под модель Kuroha: русскоязычная UGC-платформа,
где переводчики и команды загружают главы, а читатели смотрят их бесплатно.
Тексты оригинальные. Структура тем взята из типовых документов UGC-платформ,
формулировки и условия — свои.

## Состав

| Файл | Назначение |
|---|---|
| `terms.md` | Пользовательское соглашение: правила сайта, аккаунты, роли, UGC, модерация, ответственность. |
| `copyright.md` | Авторское право: права на сайт, контент переводчиков, лицензия платформе, переводы, атрибуция. |
| `dmca.md` | Правообладателям: российский порядок ограничения доступа по ст. 1253.1 ГК РФ и блок DMCA для США. |
| `offer.md` | Публичная оферта о доступе к сайту. Для бесплатной библиотеки — безвозмездный доступ. |
| `privacy.md` | Политика конфиденциальности: какие данные собираются, зачем, кому передаются и как их удалить. |
| `publishing.md` | Правила публикации: права, формат глав, метаданные, возрастные метки, модерация и апелляция. |

## Что уточнить перед публикацией

- Оператор: «Оператор проекта Kuroha»; ИНН, ОГРН и адрес не добавлялись.
- Домен: `kuroha.org`, контакт: `hello@kuroha.org`.
- Будет ли монетизация: донаты, реклама, подписка, платные главы.
- Кто отвечает за модерацию и рассматривает жалобы.
- Возрастная политика: 18+ только для отдельных тайтлов или для всего сайта.
- `privacy.md` нужно проверить по 152-ФЗ и дополнить, если появится аналитика
  или платежи.
- Юрисдикция и аудитория: Россия, СНГ, ЕС, США. Для ЕС может понадобиться
  отдельный GDPR-анализ, для США — DMCA-агент.

## Важные оговорки

1. **DMCA — это американский закон.** Для России основной механизм —
   уведомление информационного посредника по ст. 1253.1 ГК РФ. В `dmca.md`
   есть оба блока, но их нужно проверить с юристом.
2. **Публичная оферта для бесплатного сайта не обязательна.** Она включена,
   потому что ты её просил. Если появятся платные функции, оферту придётся
   переписать: появятся цена, оплата, возвраты и потребительские права.
3. **Перевод — производное произведение.** Разрешение нужно и от автора
   оригинала, и от переводчика. Одного согласия переводчика недостаточно.
4. **Модерация не заменяет юридическую проверку прав.** Площадка может
   запросить подтверждение, но ответственность за загруженный материал
   остаётся на пользователе.
5. **Тексты не копируют Senkuro, Remanga или другой сайт.** Не заменяй
   отдельные абзацы чужими: это создаёт ровно тот риск, от которого
   защищает DMCA-раздел.

## Порядок проверки

1. Заполнить реквизиты и контакты.
2. Сверить определения и перекрёстные ссылки между четырьмя файлами.
3. Проверить сроки, подсудность и ограничения ответственности с юристом.
4. Сверить политику персональных данных, правила публикации и правила модерации.
5. Поставить дату редакции и опубликовать на отдельных страницах сайта.
6. Проверить, что ссылки на документы есть в футере и при регистрации.
