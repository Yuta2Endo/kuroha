Сервер · v0.1

Твой аккаунт.
По-настоящему.

Первый backend-слой Kuroha: аккаунты, токены, серверное состояние и жалобы. Это отдельный Node-процесс без внешних зависимостей — можно запустить рядом с прототипом.

Состояние backend

Проверяем сервер…

API слушает 127.0.0.1:4180. Если сервер не запущен, локальная версия продолжает работать.

Войти или создать.

Сервер · admin

Загрузка глав.

Файлы страниц сохраняются в server/uploads и получают публичный URL. Это локальное файловое хранилище — позже его место займёт S3/R2.

Модерация

Жалобы сервера.

Очередь из API. Доступна только пользователю с ролью admin. Жалобы можно решить, отклонить или вернуть в работу.

Пока тихо. Новые жалобы появятся здесь.

API

Что уже есть.

Zero-dependency Node API на порту 4180. Данные лежат в server/db.json; сессии — в памяти процесса и файле.

GET /api/healthстатус
POST /api/registerаккаунт
POST /api/loginтокен
GET /api/stateснимок
PUT /api/stateсохранение
POST /api/reportsжалобы

Запуск

Два процесса.

Сайт: python -m http.server 4177.
API: node server/server.js в папке server.

Границы

Это не production.

Нет HTTPS, email-подтверждения, rate limit, админ-ролей в UI и настоящего файлового хранилища. Токен лежит в localStorage. Для запуска нужен отдельный security-проход.
